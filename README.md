# Двор. Пожиратель магии

Мультсериал в 14 сериях (2 часа): три пацана из панельного двора проваливаются через гараж №13 в пиксельный мир магии.

**Смотреть онлайн: https://alixanb376-dot.github.io/film/**

## Что где лежит

- `index.html` — плеер (один файл, без библиотек и фреймворков).
- `ep/epNN.mp4` — серии в 480p, каждая меньше 20 МБ; `ep/epNN.jpg` — обложки серий.
- `episodes.json` — список серий.

Плеер запоминает место просмотра, сам включает следующую серию и работает на мобильных.
Серии можно скачать напрямую из папки `ep/`.

Исходники фильма (сценарий, движок рендера, войс-лист) лежат в репозитории `fulldesk`, ветка `claude/funny-fermi-q4r6aj`, папка `film/`.
